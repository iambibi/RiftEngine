Aucune version pré construite sera donné, sur le github. Si vous voulez tester, compilez le.

## 🤝 Rejoindre le développement.
1. Commencez par forker le dépôt et rejoindre le [Discord](https://discord.gg/aywen)
2. Assurez-vous de bien suivre [CONTRIBUTING.md](https://github.com/ServerOpenMC/PluginV2/blob/master/CONTRIBUTING.md)
3. Une fois que votre idée d'implémenter quelque chose, et qu'elle marche vous pouvez ouvrir votre PR
4. Après approbation, elle sera testé sur un sevreur de test avec plusieurs comptes (java/bedrock)
